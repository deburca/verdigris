# Task: Scope marketing and enquiry flow for hive sensors

## Description
Sensors (weight and climate) are planned to be marketed from this site.
HiveLog already has the receiving side: the `nanoprobe` submodule and a
`hardware/` directory with a weight-sensor design and receiver, inside the
module. What does not exist is the commercial side.

## Acceptance criteria
- [ ] Decide what is sold (kit, assembled sensor, design only) and in which
      countries
- [ ] Product page content: photos, what it measures, how it reports into
      HiveLog
- [ ] Decide how orders or enquiries are handled (interest form only, or a
      shop; see the rental task for the Commerce question)
- [ ] CE / radio and battery compliance questions noted before selling
      hardware
- [ ] Update the interest form options and the landing page when ready
